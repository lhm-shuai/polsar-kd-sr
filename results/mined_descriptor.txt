Low-complexity descriptor (Pmv, Eq. (13))
------------------------------------------
    Pmv = exp( -c / (Pm + Pv) ),   c = 0.20430441

    c is the mean of the five official seeds (42, 123, 211, 666, 789):
        42 -> 0.21386275   123 -> 0.21064375   211 -> 0.21132621
        666 -> 0.20430441  789 -> 0.20927252
        mean = 0.20988, maximum relative deviation 2.66%

    Node complexity 6; three floating-point operations per pixel.

    exp(-c/x) is strictly monotone in x = Pm + Pv, so the descriptor has the
    same ranking and AUC as the raw sum. Its value is a closed form, costs
    three operations, and maps to (0, 1) with the saturation behaviour of a
    membership probability. scripts/04_evaluate.py prints both the descriptor
    and the raw sum so the mapping can be checked directly.


High-complexity descriptor (Psmv, Eq. (16), Table IV)
-----------------------------------------------------
    Psmv is the complexity-29 point of the seed-666 Pareto front:

        A = exp( Pv * (-0.72197366 - Ps) ) / ( Pm^2 + 1.0250757 )
        t = cos( A^8 + 0.48293668 )
        t = sin(t) / 0.61469054
        t = sin( sin(t) )
        t = t^2 / 0.49011374
        Psmv = sin(t)^8

    This is the canonical Psmv used by the paper: Eq. (16), the last row of
    Table III, and the high-complexity detector input. The same expression is
    implemented as `psmv` in `src/evaluate.py`.
